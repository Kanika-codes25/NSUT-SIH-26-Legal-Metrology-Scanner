# Submission Guide

## Project

**Legal Metrology Scanner**

## Problem Statement

**PS Number:** SIH26034

**Problem Statement Title:**

Software System to check compliance of Packaged Commodities under Legal Metrology(Packaged Commodities) Rules, 2011 by scanning products, images and labels.

**Organization:** Ministry of Consumer Affairs, Food & Public Distribution

**Category:** Software

**Theme:** Miscellaneous

## Repository Structure

- `src/` — Project source code
- `docs/` — System architecture and workflow documentation
- `assets/screenshots/` — Project screenshots
- `submission/` — Presentation and demo details
- `requirements.txt` — Python dependencies

## Important Notes

- This repository contains the project implementation and submission documentation.
- The system performs automated screening based on selected Legal Metrology requirements.
- The result is intended as an inspection assistance tool and not as official legal certification.
